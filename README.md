
# Sistema Bancário POO

## Descrição
Sistema bancário desenvolvido em Python utilizando Programação Orientada a Objetos (POO), com classes para clientes, contas bancárias, conta corrente e conta poupança.

## Tecnologias Utilizadas
- Python 3
- Programação Orientada a Objetos (POO)
- Git e GitHub
- Visual Studio Code

## Estrutura do Projeto

```text
sistemabancario_poo/
├── __pycache__/
├── .gitignore
├── app.py
├── cpcliente.py
├── cs01conta.py
├── cs02contacorrente.py
├── cs03contapoup.py
└── README.md
```

## Arquivos do Projeto

- `app.py`: arquivo principal para executar o sistema.
- `cpcliente.py`: classe responsável pelos dados do cliente.
- `cs01conta.py`: classe base de conta bancária.
- `cs02contacorrente.py`: classe de conta corrente.
- `cs03contapoup.py`: classe de conta poupança.
- `.gitignore`: define quais arquivos e pastas não devem ser enviados ao GitHub.

## Funcionalidades

- Cadastro de clientes.
- Criação e gerenciamento de contas bancárias.
- Consulta de saldo.
- Depósitos e saques.
- Transferências entre contas.
- Consulta dos dados do cliente.
- Consulta dos dados da conta.
- Consulta de limite de crédito.
- Cálculo de rendimento da conta poupança.
- Listagem e desativação de contas.

## Como Executar

1. Instale o Python 3.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o terminal integrado.
4. Execute o comando:

```bash
python app.py
```

No Windows, se necessário, utilize:

```bash
py app.py
```

## Conceitos de POO

- **Classes e objetos:** representam clientes e contas bancárias.
- **Encapsulamento:** organiza e controla o acesso aos dados.
- **Herança:** permite especializar a classe de conta bancária.
- **Polimorfismo:** permite implementar comportamentos específicos para diferentes tipos de conta, quando aplicável.
